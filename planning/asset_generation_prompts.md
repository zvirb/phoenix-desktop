# Asset Generation Prompts for Phoenix Desktop

This document contains a series of text-to-image prompts designed to generate the missing UI assets for the Phoenix Desktop application. These prompts are optimized for the **Nano Banana** model (or similar high-fidelity Stable Diffusion checkpoints), focusing on the three core visual themes identified in the prototypes.

## 1. Global Style Parameters
*Apply these keywords to all prompts to maintain consistency.*
> **Keywords**: UI design, interface aesthetics, dark mode, high fidelity, 8k resolution, figma export, dribbble style, sleek, modern, cyber-minimalism, neon accents, glassmorphism.
